# 2026-07-09

## URL Guard 拆分 hostname / url 两套拦截（实现完成）

用户要求对"具体网址拦截（hostname + 接口形式）"实现两种独立方式并同时校验。

### 改动文件
- `src/qwenpaw/security/tool_guard/url_guard/__init__.py`
  - `UrlGuardian` 新增 `blocked_hostnames`（域名级，匹配 hostname 整域）与 `blocked_urls`（接口级，匹配完整 URL path）两套独立黑名单。
  - rule_id 由旧的 `URL_BLOCKLIST` 拆为 `URL_BLOCKLIST_HOST` / `URL_BLOCKLIST_URL`。
  - `_check_url` 中两个检查独立运行：命中任一即产生对应 finding；同时命中则各出一 finding（"同时校验"语义）。
  - `browser_use` 接入 `_URL_AWARE_TOOLS`，扫描 `url` / `cdp_url` / `actions_json`（dict/list 经 `_param_to_text` 序列化为文本后提取 URL）。
  - 新增 `_match_hostname_blocklist` / `_match_url_blocklist` / `_param_to_text`；`_load_url_guard_config` 返回四元组。
  - 内置 `csdn.net` 移入 `_BUILTIN_BLOCKED_HOSTNAMES`。
- `src/qwenpaw/config/config.py`：`UrlGuardConfig` 增加 `blocked_hostnames: List[str]` 字段。
- `src/qwenpaw/security/tool_guard/utils.py`：`auto_denied_rules` 默认集改为 `{URL_BLOCKLIST_HOST, URL_BLOCKLIST_URL, URL_LOOPBACK, SHELL_EVASION_URL_VARIABLE_HOST}`。
- 测试与文档同步更新（`test_url_guardian.py` 新增 `TestBrowserUse`，docs 更新）。

### 注意
- 真实 `~/.qwenpaw/config.json` 中旧的 `blocked_urls: ["*csdn.net*"]` 已迁移到 `blocked_hostnames`（新语义下 blocked_urls 只匹配完整 URL）。
- 之前会话已实现的 `SHELL_EVASION_URL_VARIABLE_HOST`（shell 变量拼接 hostname 检测，直接拒绝）仍生效。
- CDP 网络层拦截（Playwright route 拦截，兜底 JS 跳转绕过）**仍未实现**，属于后续可选项。
